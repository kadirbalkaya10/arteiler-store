Build or update following UI :

$ARGUMENTS 

1. Inspect the current UI to understand the existing design components, patterns, and layout.
2. Search for reusable design components and patterns that can be leveraged in the new UI.Before creating a new one.
3. Reuse existing design components and patterns wherever possible to maintain consistency and reduce development effort.
4. Keep the changes focused on the requested feature.
5. Verify responsive behavior across different screen sizes and devices to ensure a consistent user experience.
6. Run and visually inspect the updated UI to ensure it meets the design requirements and functions correctly.
7. Run the normal project checks.
8. Fix reproducible issues without expending scope.
9. Summarize what changed.
